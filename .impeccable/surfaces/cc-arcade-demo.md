# cc-arcade browser demo

Mode: Operate. Extend the shipped Community Shelf world; no identity replacement.

User request: make cc-arcade's 2048 playable in the browser, keep the current design, and add a “Try this mod” button to its listing.

Route: /mods/cc-arcade/demo. The board is the primary task and appears in the first viewport. Desktop pairs a compact game column with the existing hand-drawn arcade artwork, author credit, source, and installation link. Phones put the game first and stack the supporting context below. Reuse Newsreader headings, Inter controls, ivory paper, ink, rust, sage, modest corners, and flat resting surfaces. No extra heading kicker.

Controls: focused-board arrow keys or WASD, touch swipes, and visible directional buttons. Score, best tile, new game, one-step undo, win/continue, and no-moves states. Input stays scoped to the board. Controls remain reachable at 44px or larger; visible focus and polite state announcements are required. Preserve page scrolling outside the board and pinch zoom. Repeated moves render immediately without decorative animation.

Product truth: this is a browser adaptation of the pinned MIT-licensed cc-arcade rules, not a running Claude Code session. Credit Seza Akgün and link the original source and license. No credentials, backend execution, or new dependencies.
