# cc-arcade browser demo

The current contract is [mod-terminal-demos.md](mod-terminal-demos.md). It supersedes the previous standalone-game contract following the user's request for prompt-driven work/reply loops across every mod. The arcade board still follows pinned cc-arcade 2048 rules, glyphs, ANSI colors and AbovePrompt placement. The complete MIT license remains at public/licenses/cc-arcade-MIT.txt. Only 2048 is playable; other upstream arcade games are explicitly outside this browser subset.
