# Core demo source fidelity

Audit date: 2026-10-12. This covers `cc-arcade`, `cctop`, `flowpane`, `mindful-claude`, `context-lens`, `cc-dino`, and `clawd-buddy`. It compares each catalog pin with the current default-branch commit returned by the official GitHub API. Both source archives were inspected as text; none of the downloaded code was executed. Current HEAD equals the catalog pin for every repository below.

The demo renders local state in xterm. Claude replies, tools, agents, account telemetry, token-count results, and workflow results are fixtures. That boundary does not establish visual or behavioral equivalence; the remaining differences are listed explicitly.

## Corrections and remaining differences

### cc-arcade

The native 2048 renderer uses a 27-column round board, gray empty dots, value-specific colors, and bold tiles from 128. The row above it has `← games` and `close`. Restart is `r`; the previous extra restart button inside the board has been removed. The status now includes score, winning-with-continued-play wording, click/arrow/WASD help, restart help, best score, and the source yellow completion banner. The picker puts its command hint before the available game buttons.

The demonstration starts with `/arcade 2048`; the source starts with no open board and opens through `/arcade`. Only 2048 is playable here. The source also has Snake, Tetris, Doom, Minesweeper, Flappy, Pong, Typing, Invaders and Pet, plus random/auto selection, colorblind Doom and persistent pet/score storage. Those surfaces are absent. The 2048 browser state also retains an undo capability that the native board does not expose; the native rendering does not add an undo control.

### cctop

The audited surface is the Claude Code plugin pane, not the separate Rust binary's full-screen TUI. The source reserves `/cctop` for its skill and registers `/cctop-pane`; the native tab order is Coach, Overview, Tools, Agents, Files, Events, Advisor. Overview is the default and home is Events. Selected tabs use inverse text, not surrounding square-button chrome. The six numbered Overview cells use the native two/three-column width ladder, with BUSY/IDLE/WAITING glyphs and a selectable body under a `0: home` rule. The source gauge uses `▇` and `▁`, and frames use round corners and padded vertical borders.

Tools now aggregates tool names under `TOOL CALL ERR P50 P95 →CTX`; Agents uses `Agents & MCP`, Files uses touch/edit columns, and Events preserves oldest-first event order. Source frame numbers are Tools 5, Agents 6, Files 7, Events 8, Advisor 9. Account windows, cache age, elapsed timings, token estimates, file deltas, costs and advice are explicit fixtures rather than a running cctop collector. Coach uses a quiet fixture and does not recreate nudge fill/snooze/why actions. Agents lacks native nested workflow, teammate, task and MCP details. Advisor lacks native model-produced steps/history. Table widths and omitted optional columns follow a reduced local data shape rather than every native collector schema.

### flowpane

Main thinking alone cannot create a workflow. Manual `/flowpane` opens the source idle message before any Workflow call. A Workflow fixture opens the graph and retains it after completion and during a following main turn. Both research agents finish at the phase barrier before implementation starts; the prior overlapping phase sequence was incorrect.

The pane uses the Tokyo Night background/palette, source title/run rules, heavy done/stopped glyphs and a spinner for running agents. Cards put the centered name and state in the top edge, elapsed/token facts inside, and model in the bottom edge. Tool text belongs in details. Horizontal phases run across the pane; vertical phases run down it; list has rows grouped by phase; timeline has an axis and duration-aligned lanes. The footer exposes Settings and `flowpane 0.10.0`. Current source documentation takes precedence over the older `0.3.0` screenshot.

Details now appear over a dim, noninteractive graph, with an inset frame, centered title, corner close control and one active Prompt/Tool Calls/Thinking/Response tab. Closing retains the selected layout. The body contains local task/tool/thinking/result fixtures. It does not include native call drilldown, shelves, scroll/wrapped long output, nested runs, fleet metrics, attempts, fan/loop rails or the full edge router. Horizontal overflow is clipped without the source scroll rails; node geometry and connectors are a small three-agent drawing. Timeline is a reduced trace, without every source ruler/grid/now-marker/fact-column behavior. Settings is a layout chooser instead of the source dropdown dialog with twelve themes and height controls (5–32 rows). Automatic layout uses width rather than the source width/height proportions, since the adapter receives columns only.

### mindful-claude

Verified defaults are enabled, exercise `hrv`, style `random`, delay `0`, spinner `true`. Native exercises are coherent 5.5/5.5 seconds, sigh 4-second inhale + 1-second sip + 10-second exhale, box 4/4/4/4 seconds, and 4-7-8. Pulse, ripples, dots and wave use the native seven-row shapes, glyphs, width cap, lung-progress easing and empty initial frame. The orange phase line and dim exercise label complete the nine-row band. The native phase is forwarded to the spinner when enabled; delay is measured from turn start and does not restart the breathing cycle when the band mounts.

Commands match the native exercise/style/delay/spinner families; bare `/breathe` reports settings rather than toggling. The band mounts while working and disappears at completion. Native random style excludes the last style; the demo repeats the four-style cycle to make runs reproducible. Native painting ticks at 100ms; the shared browser fixture clock ticks at 400ms. The renderer receives no terminal-height/survey-dialog context, so it always draws the normal nine-row band rather than the source's short-band cropping and survey suppression.

### context-lens

The old guessed category ratios and fixed 160k auto-compaction threshold were removed. Metadata now supplies actual category names/tokens/colors/kinds, exact used tokens, model, window, and threshold. Categories skip deferred/zero entries, sort used rows by descending token count, then buffer, then free. Bars and labels obey native width caps. Exact totals are separate from rounded percentages. Completed-turn exact totals drive the last delta and the last five positive growth samples, with a 24-reading history. Forecasts clamp at zero and say `compact next turn` or `full next turn`, with singular/plural and `99+` wording. Status truncates at 70 characters.

The integrated fixture copies the [official README example](https://github.com/Arunjay4213/claude-mods/blob/d4fffd7de9204a62b10e7b3604fc893158fa25fd/plugins/context-lens/README.md#L23): 45,900 used tokens, a 1,000,000-token window, 800,000 compaction threshold, model `claude-opus-5`, and category counts Messages 22,400 / System Tools 14,200 / Memory Files 4,900 / System Prompt 3,100 / Auto-compact Buffer 45,000 / Free Space 910,000. This is a documented source example, not a native universal default. Its rounded values/categories are not a mathematically exact sum. Later completed fixture turns add 8,000 tokens to total and Messages. Category semantic colors are local fixture choices because the native API supplies colors and the README text does not specify them.

Without metadata, the native total-only/window-itself fallback is preserved instead of fabricating categories or a threshold. Refresh changes the counted label locally; no real token-count request is sent. Main completion updates the reading; a new work turn retains it. Compact/clear resets the metadata and growth history. The native session-start read can show an initial host estimate; the demo waits for its first completed fixture answer. Failed host-reading retention cannot be exercised because no host API is connected.

### cc-dino

Standing/duck half-bitmaps, bird flap glyphs, half-cell compositing, cloud positions, ground marks, cactus/tall/cluster colors, and night stars/palette now follow the native board. The sprite begins at column 2; its hitbox begins at column 4 and spans three cells, as the source does. Native controls and status wording include close, Space/up jump, down duck, pause, score, record, and the yellow completion banner. `/dino reset` clears best rather than opening/restarting a run. Completion pauses once; a fresh main prompt does not automatically resume it.

The native physics uses 33ms frames, a 20-frame fitted jump arc, speed 0.45 with acceleration 0.000175 capped at 1.2, timed duck of 18 frames, multiple random obstacles, and birds from score 200. The browser uses independent 400ms ticks, a six-tick sampled arc, a short timed duck, one deterministic obstacle sequence, and fixture score/distance. Jump height, cadence, collision trajectory, ground/cloud movement speed, gait/flap cadence, obstacle density and difficulty therefore differ. Native night changes every 700 score; that threshold and colors are reproduced. The fixed demo sky is nine rows; source height adapts to its surface and refuses an undersized band. This is not a native-frame-rate Dino port.

### clawd-buddy

The source is a 100-column by 14-pixel stage, drawn as seven terminal rows; the canonical figure origin is `(60,4)`, leaving 23 columns past its body for props. Narrow viewports crop from the left rather than shifting Clawd to the final 24 columns. The demo now retains that reserve, native orange body/outer arms, darker front arms, black eyes, four standing feet and the half-cell upper/lower colors. The earlier invented completion smile was removed: source stage deliberately draws no mouth except whistle. Thinking uses the chin arm; reading uses the native scroll pattern; editing uses the open profile laptop and alternating hands/three-quarter shadow. Composer watching, blink and completion use selected local poses.

The source runs at 75ms and schedules whole entrance/action/exit clips. The demo's 400ms clock switches among selected poses and prop frames: it does not reproduce the clip scheduler, fetch-in/out choreography, all work/shell/web/game/celebration clips, sidekicks, mouse dragging, mood/temper/hour/nap/tired states, birthday behavior, reduced-motion settings, language settings, or desktop rendering. Props appear directly when the fixture event changes. The canonical pose is source-derived; the full animation is not equivalent.
