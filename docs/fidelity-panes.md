## Shared integration

The renderer uses these shared contracts: copy actions carry optional `text` and support `art`; `taskClearTick`/`taskClearAll` preserve source-specific clearing; Taskline also supplies individual removal timestamps and check request ticks; browser supplies history/index, menu and grab-selection state; Filetree supplies `hidden`, `atParent`, and persistent `modified`; PR review supplies `quote`; Flightdeck reset records the turn and entry cutoffs. `renderPrismantisTranscriptEntry` formats user, assistant and tool rows in the shared terminal frame rather than rendering a second generic transcript.

The browser keeps network services, account usage, filesystem contents, PR data and model replies as explicit fixtures. It does not load upstream code or run external tools. The source's host-specific services and per-user terminal theme cannot be connected from a static browser demo. The local timer advances every 400ms, so native 200ms attachment polling and 500ms progress-file writes are represented at that browser resolution.
