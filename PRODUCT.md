# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

TypeScript, React, and Next.js. Deployed to Vercel from the public Ross-cripto/modshelf GitHub repository.

## Users

Claude Code users discovering useful mods, and open-source contributors sharing their own mods and artwork.

## Product Purpose

An independent open-source marketplace exclusively for Claude Code function-hook mods.

## Capabilities and Constraints

Search, category filters, sorting, browser-local bookmarks, source links, and installation instructions. The catalog is version-controlled JSON. Contributions use project skills and reviewed pull requests. The website needs no database, accounts, AI API keys, or environment file. All website copy is English. Generic skills, prompt packs, MCP servers, and ordinary shell hooks alone are outside the catalog.

## Brand Commitments

Preserve the approved community-shelf design: generous spacing, ivory paper, charcoal ink, muted rust and sage, Newsreader headings, quiet Inter controls, and consistent hand-drawn ink illustrations. DESIGN.md records the shipped design system.

## Evidence on Hand

Catalog entries link to their original repositories and function-hook source. New reviewed listings include commit-pinned evidence, declared license sources, and generated artwork with exact prompt/time provenance. Source review does not certify runtime behavior. No popularity scores or testimonials are supplied.

## Product Principles

- Make discovering a useful mod the primary task.
- Keep source and installation instructions easy to inspect.
- Keep the creator's authorship and licensing visible.
- Add listings and matching artwork through the repository.
- Preserve factual claims and the approved visual world.
