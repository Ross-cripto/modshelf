# Security

## Report a vulnerability

Use [GitHub's private vulnerability report](https://github.com/Ross-cripto/modshelf/security/advisories/new) for vulnerabilities in the Modshelf website or contribution tooling. Include the affected version or commit, reproducible steps, and the expected impact. Remove passwords, API keys, and personal data from examples.

Use public issues for ordinary bugs. Security reports are reviewed by the project maintainer; no response-time guarantee is offered.

## Third-party mods

Modshelf links to independent mod repositories and publishes source-linked installation instructions. It does not execute those mods or certify their runtime behavior. Report vulnerabilities in a listed mod to its own maintainer using that repository's security policy.

## Supported versions

The current main branch is maintained. Reproduce website or tooling issues on the latest main branch when possible, and include the version of Node.js and Claude Code used.
