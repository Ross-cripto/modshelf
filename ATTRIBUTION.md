# Content sources

The marketplace is inspired by the Claude Code mods community at https://claudemods.ai/. Its page layout, summaries, and illustrations were created for Modshelf.

Initial source-linked mods:

- CC Arcade — https://github.com/sezaakgun/cc-arcade
- cctop — https://github.com/tomstagl/cctop
- flowpane — https://github.com/mpolatcan/flowpane
- Mindful Claude — https://github.com/halluton/Mindful-Claude
- context-lens — https://github.com/Arunjay4213/claude-mods/tree/main/plugins/context-lens
- cc-dino — https://github.com/manfye/cc-dino

Each repository retains its own license and authorship. This project contains links and installation instructions, not copies of the listed mod packages.

Self-hosted typefaces: Newsreader and Inter, from Google Fonts, SIL OFL 1.1. Lucide icons are distributed under ISC.
